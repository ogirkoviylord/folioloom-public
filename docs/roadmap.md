# Product roadmap

FolioLoom is pre-MVP and actively developed. This roadmap describes product direction, not delivery dates or a commitment to public availability.

| Focus | Intended outcome |
| --- | --- |
| Document and terminology foundations | Bring TXT, DOCX and EPUB processing together with terminology decisions authors can review and approve. |
| Connected author workflow | Connect document setup, glossary work, draft translation, review and export in a coherent workbench. |
| Representative evaluation | Examine terminology consistency, meaning and document structure using authorized evaluation material. |
| Author feedback | Test whether the workflow helps authors and rightsholders make understandable, useful translation decisions. |
| Broader access, when supported by evidence | Determine suitable access arrangements after workflow, quality and reliability validation. |

The immediate emphasis is author control and a useful, reviewable draft. Automatic glossary assistance and broader access require further validation. Alpha, beta and public launch dates are not announced.
