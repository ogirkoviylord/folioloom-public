# Security reporting

To report a suspected security vulnerability affecting FolioLoom or this repository, email [hello@folioloom.com](mailto:hello@folioloom.com) with the subject **Security report — FolioLoom**.

Include a concise description, the affected public page or component, and reproduction steps that do not disclose sensitive information.

Please do not publish vulnerabilities, credentials, user documents or private information in public GitHub issues. Do not send passwords, API keys or raw user documents in an initial report. If sensitive evidence is needed, contact us first to agree how to share it.

This repository contains public project documentation. FolioLoom remains pre-MVP; this reporting channel does not imply a production security certification or a bug bounty program.
